# Backup gallery

Example results that the notebook shows to students whose Colab session has no GPU.

This folder is empty until you build it. Open `sd_lab.ipynb` in Colab on a T4 GPU, run **⚙️ Setup**, then run the last cell (**🧑‍🏫 Instructor only**) with `export_now` ticked. Unzip the downloaded `gallery.zip` here, so that `first.jpg`, `denoise.jpg`, `denoise.gif`, `seed.jpg`, `steps.jpg`, `cfg.jpg`, `negative.jpg`, `img2img.jpg`, `bias.jpg` and `inpaint.jpg` sit next to this file. Then push to GitHub.
